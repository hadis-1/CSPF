# Annotation guidelines (second annotator)

You see an ORIGINAL text and a PERTURBED text. Do not look at any other file. Fill three columns for each row.

**meaning_a2** — does the perturbed text keep the propositional content of the original (who did what / what is evaluated)?
- `yes`: same content; only wording, register, emphasis or a harmless aside differs.
- `partial`: content is kept but the strength, certainty, stance or tone is noticeably changed (e.g. 'good' -> 'not bad', 'I suppose' hedging, intensity reduced).
- `no`: a different claim, or the meaning is reversed or lost.

**sentiment_a2** — is the overall sentiment polarity toward the target (positive / negative) the same as in the original?
- `yes`: same polarity. `unclear`: you cannot tell or it became neutral/ambiguous. `no`: opposite polarity.

**natural_a2** — would a fluent speaker plausibly write the perturbed text?
- `yes`: natural. `borderline`: understandable but awkward. `no`: ungrammatical or clearly artificial.

Rules: judge each row independently; use only the allowed values (lower case); put doubts in `comment_a2`; do not discuss rows with the first annotator until finished. Expected time: about 4 hours for 576 rows.
